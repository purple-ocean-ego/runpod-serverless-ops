# 対話ワークフロー詳細

SKILL.md の 5 ステップを実際に進めるための詳細手順・質問リスト・チェック基準・秒割り指針。

---

## Step 1: 参照素材の確認（ヒアリング）

### 確認するもの
- 対象素材のパス（参照画像 / 参照動画 / 参照音声）。
- 各素材の**役割**はユーザーにヒアリングして確定する（R2V では各参照が特定の要素を担う）。

### 役割ヒアリングの質問例
```
- この参照画像は何を担いますか？（体格 / 構図と体の向き / 顔の造形 / 表情）
- どの参照画像が「体の向き」、どれが「顔」を決めますか？
- モーション（動き・カメラ）はどの動画から取りますか？
- 音声・環境音・音楽はどの音声トラックから取りますか？
- 参照画像と動画で向きが食い違っている場合は、どちらを優先しますか？
```

### 確認する属性
- 画像: 解像度・アスペクト比・縦横。
- 動画: 解像度・長さ・fps・カメラワーク。
- 音声: サンプルレート・チャンネル・内容（環境音か BGM か）。

---

## Step 2: 内容チェック（Checks）

### 素材の読み取り
- 動画/画像は実際にフレーム抽出して内容を確認する（構図・カメラ・被写体の向き・雰囲気）。
- 音声はスペクトル・音量で BGM/環境音の有無を大まかに判断する。
- ffmpeg が使える環境なら: `ffmpeg -i ref.mp4 -vf "fps=1/2" out_%02d.png` でフレーム化。

### メモする項目（後で秒割り・記述の根拠）
- 構図: どの位置に被写体がいるか、カメラの角度（見下ろし / 低アングル / 寄り / 引き）。
- カメラワーク: 固定 / ドリー / パン / 手持ち。変化のタイミング。
- 雰囲気: 照明の種類（自然光 / 人工光 / 単色背景）、明るさ・温度感、質感の有無。
- 被写体の向き: 体の向き、顔の向き、視線の方向。カメラに対する相対位置。
- 時間的な変化: 冒頭の状態 → 動作のピーク → 収束、の流れ。

---

## Step 3: 秒割り提案

### 指針
- 総時間を、**モーションが変化する瞬間**で骨切りする。目安 2〜4秒/ショット。
- 各ショットに開始タイムコードを付ける（`At 00:00.000, ...`）。境界は「その Shot が始まる秒」で書き、重複させない。
- 音声側の変化（静→動・ピーク・収束）も境界の根拠にする。
- 冒頭に静止導入、終盤に収束ショットを入れる。

### タイムコードの書式
- 統一して `00:00.000`（分:秒.ミリ秒）を採用。
- 最終ショットの終端は素材の総時間に揃える（例: 14.03s なら 00:14.000 で終わる）。

### ユーザー承認
- 提案した秒割りを一覧で示し、境界タイミングの妥当性を確認してもらう。
- 修正があれば反映する。

---

## Step 4: カスタマイズヒアリング

### ヒアリング項目
- キャラや構図の指定（キャラの同一性は参照画像に頼るか、プロンプトで補足するか）。
- 強調したい動き・カメラワーク。
- 音声・音楽の扱い（環境音のみ / BGM あり / ピークタイミング）。
- 全体トーン（シネマティック / 穏やか / エネルギッシュ 等）。

### 反映の原則
- ヒアリングした内容は、**素材の内容を損なわない範囲**でプロンプトに反映する。
- 素材に無い要素を付け加えたり、向き・人物関係を書き換えたりしない（ガードレール2）。

---

## Step 5: プロンプトに反映・提示

- `references/prompt-template.md` の標準構造に対話結果を反映する。
- 形式的な整合は公式ガイドに従って確認する（**MiniMax H3 出力書式ガイド** <https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md>）。
- 反映前に、**素材と照合して矛盾がないか**を最終チェックする（ガードレール2）。
- 完成したプロンプトを提示し、ユーザー確認を取る。

### 最終チェックリスト
- [ ] `subject_definitions` の `<Picture N>` / `<Video N>` が実際のマッピングと一致しているか。
- [ ] `detailed_description` の秒割りが Step 3 の承認済みタイムコードと一致しているか。
- [ ] 素材に無い要素・表現を足していないか。
